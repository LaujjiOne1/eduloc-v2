⚠️ Ne communiquez JAMAIS votre code PIN

edUloc ne vous demandera jamais votre code secret Mobile Money. La confirmation du paiement se fait uniquement sur votre téléphone via USSD ou application officielle.

  • Ne donnez jamais votre PIN à un agent edUloc
  • ❌ Ne saisissez jamais votre PIN sur ce site
  • ✅ Confirmez uniquement sur votre mobile
  • ✅ Vérifiez que le numéro affiché correspond à votre numéro

Informations de paiement

Le numéro doit être associé à un compte Mobile Money actif

Comment ça marche ?

  1. Étape 1 : Entrez votre numéro de mobile ci-dessus
  2. Étape 2 : Cliquez sur "Payer"
  3. Étape 3 : Vous recevrez une demande de paiement USSD sur votre téléphone
  4. Étape 4 : Saisissez votre code PIN confidentiel uniquement sur votre mobile
  5. Étape 5 : Confirmez le paiement dans l'USSD

Statuts de paiement

⏳
En attente

La demande a été envoyée. Attendez la confirmation.

✓
Confirmé

Paiement réussi et vérifié côté serveur.

✗
Échoué

Le paiement a été refusé ou annulé.

⏱️

Vérification automatique

Après confirmation USSD, notre système vérifie automatiquement le statut du paiement auprès de l'opérateur. Cette vérification peut prendre jusqu'à 2 minutes.

Ne fermez pas cette page avant la confirmation finale.

📱

Important concernant les preuves de paiement

Un SMS de confirmation ou une capture d'écran ne suffit pas à valider votre réservation. Seul le statut confirmé par l'API de l'opérateur fait foi.

En cas de problème, contactez notre support avec la référence de transaction.
