Questions fréquentes sur les paiements

🔒 Sécurité et confidentialité

Mes données bancaires sont-elles en sécurité ?

Oui, absolument. edUloc utilise un prestataire de paiement certifié PCI DSS Niveau 1, le plus haut niveau de certification pour la sécurité des cartes bancaires.

  • Vos numéros de carte ne transitent jamais par nos serveurs
  • Le CVV n'est jamais stocké (interdiction PCI DSS)
  • Toutes les transactions sont chiffrées (HTTPS/TLS)
  • Authentification 3D Secure obligatoire
Puis-je enregistrer ma carte pour les prochains paiements ?

Non, par mesure de sécurité, edUloc ne conserve pas les numéros de carte complets. Conformément à PCI DSS, nous ne stockons que :

  • Un jeton (token) fourni par le prestataire
  • Les 4 derniers chiffres de la carte
  • La marque de carte (Visa, Mastercard)

Vous devrez ressaisir votre numéro de carte à chaque paiement, mais le CVV ne sera jamais enregistré.

Qu'est-ce que le 3D Secure ?

Le 3D Secure (Visa Secure) est un protocole d'authentification qui ajoute une couche de sécurité supplémentaire. Après avoir saisi vos informations de carte, votre banque peut vous demander :

  • Un code SMS à usage unique
  • Une validation via l'application mobile de votre banque
  • Une empreinte digitale ou reconnaissance faciale

Cette authentification est gérée directement par votre banque, pas par edUloc.

📱 Mobile Money

Quels opérateurs Mobile Money acceptez-vous ?

Nous acceptons les principaux opérateurs à Madagascar :

  • Orange Money (numéros commençant par 034)
  • MVol a (Telma) (numéros commençant par 032 ou 033)
  • Airtel Money (numéros commençant par 031)

L'opérateur est automatiquement détecté à partir de votre numéro de téléphone.

Est-ce que je dois donner mon code PIN ?

NON, JAMAIS ! edUloc ne vous demandera jamais votre code PIN Mobile Money. La saisie du PIN se fait exclusivement :

  • Dans le menu USSD qui s'affiche sur votre téléphone
  • Ou dans l'application officielle de l'opérateur

Aucun agent edUloc ne peut vous demander votre code secret. Si quelqu'un vous le demande, il s'agit d'une tentative de fraude.

Combien de temps pour recevoir la demande USSD ?

La demande USSD arrive généralement dans les 30 secondes suivant votre clic sur "Payer". Si vous ne la recevez pas :

  1. Vérifiez que votre téléphone a du réseau
  2. Vérifiez que le numéro saisi est correct
  3. Vérifiez que votre compte Mobile Money est actif
  4. Contactez notre support si le problème persiste
Que faire si je reçois un SMS de confirmation mais que ma réservation n'est pas validée ?

Un SMS de confirmation ou une capture d'écran ne suffit pas à valider automatiquement votre réservation. Notre système doit recevoir la confirmation officielle de l'API de l'opérateur.

En cas de désynchronisation :

  1. Attendez quelques minutes (la vérification automatique peut prendre jusqu'à 5 minutes)
  2. Vérifiez votre solde Mobile Money pour confirmer le débit
  3. Contactez notre support avec :
    • La référence de votre réservation
    • La référence de transaction Mobile Money
    • Une capture du SMS de confirmation

Nous vérifierons manuellement le statut auprès de l'opérateur.

⚠️ Problèmes et résolution

Mon paiement a échoué, que faire ?

Plusieurs raisons peuvent expliquer un échec :

  • Carte bancaire : Solde insuffisant, plafond dépassé, authentification 3D Secure échouée
  • Mobile Money : Solde insuffisant, code PIN erroné, transaction expirée

Actions recommandées :

  1. Vérifiez votre solde ou plafond
  2. Réessayez avec un autre moyen de paiement
  3. Contactez votre banque ou opérateur si le problème persiste
  4. Contactez notre support pour vérifier l'état de votre réservation
J'ai été débité mais ma réservation n'est pas confirmée

Cette situation est rare mais peut arriver en cas de problème de communication entre les systèmes.

Ne paniquez pas :

  1. Attendez 10-15 minutes (le système effectue des vérifications automatiques)
  2. Vérifiez vos emails (la confirmation peut arriver avec retard)
  3. Contactez notre support immédiatement avec :
    • Votre numéro de réservation
    • La référence de transaction
    • La preuve de débit (SMS ou relevé)

Nous effectuerons un rapprochement manuel et :

  • Soit nous confirmerons votre réservation
  • Soit nous déclencherons un remboursement sous 24-48h
Peut-on annuler un paiement ?

Avant confirmation : Oui, si le paiement est encore en statut "PENDING", vous pouvez annuler depuis votre espace edUloc.

Après confirmation : Les paiements confirmés ne peuvent pas être annulés directement. Vous devez :

  1. Annuler votre réservation (sous réserve de notre politique d'annulation)
  2. Demander un remboursement qui sera traité sous 5-10 jours ouvrés

Les remboursements sont réservés aux rôles autorisés et nécessitent une validation.

🔗 Support et CRM

Le support peut-il voir mes informations de paiement ?

Nos agents ont accès dans Odoo CRM à :

  • ✓ La référence de transaction
  • ✓ Le moyen de paiement utilisé
  • ✓ Le statut du paiement
  • ✓ Le montant et la devise
  • ✓ Les 4 derniers chiffres de carte (pour Visa)
  • ✓ Le numéro de téléphone masqué (pour Mobile Money)

Mais jamais :

  • ❌ Le numéro complet de carte
  • ❌ Le code CVV
  • ❌ Le code PIN Mobile Money
  • Les secrets API
